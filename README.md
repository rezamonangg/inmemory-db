# In-Memory Key-Value Database (Rust)

This project is a learning-focused implementation of an in-memory key-value database, inspired by Redis and Memcached, written from scratch in Rust.

## Goals
- Learn Rust and systems programming concepts
- Understand how in-memory databases work internally
- Build a simple, fast, and extensible key-value store

## Planned Features
- Basic key-value operations (SET, GET, DELETE)
- Command-line interface (REPL)
- Optional persistence (snapshot & AOF)
- Networking (TCP server for clients)
- Expiry and eviction (TTL, LRU)
